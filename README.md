# FreshMart – Online Grocery Store Web Application

FreshMart is a web-based grocery store application that simulates the core functionality of an e-commerce platform. The application allows users to browse products, add items to a shopping cart, and manage their purchases through an interactive interface.

This project demonstrates fundamental front-end development concepts including dynamic user interaction, responsive design, and client-side data persistence.

---

## Project Overview

The application provides a simple and intuitive interface for users to explore grocery products, manage their shopping cart, and view real-time price calculations. Cart data is stored locally in the browser so that users can continue their shopping session even after refreshing the page.

---

## Features

- Product catalog with category filtering and search functionality
- Shopping cart system with add, remove, and quantity controls
- Cart data persistence using Local Storage
- Responsive layout compatible with desktop and mobile devices
- Real-time price calculation for cart items
- Smooth UI transitions and interactive notifications
